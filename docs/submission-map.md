# Hackathon Submission Map

## Judging rubric

### Application of Technology

Cascade demonstrates eight agents across multiple frameworks: CrewAI triage, LangGraph coordination/forensics flows, Pydantic AI compliance and BI specialists, and a direct Anthropic SDK adversary agent. The dashboard now has a typed WebSocket relay path, so visible activity can be driven by real platform room events instead of UI-only theater.

### Presentation

The demo surface is a custom two-minute war-room dashboard with a ticking incident clock, visible specialist recruitment, live notification clocks, a business-interruption counter, and a pulsing attorney approval gate. The deterministic fallback keeps the recording tight while the relay protocol shows how live events render through the same surface.

### Business Value

The buyer is the breach-response partner coordinating ransomware incidents for insureds. Cascade targets expensive coordination work currently done across email, Slack, conference calls, and spreadsheets, while preserving attorney work product boundaries and auditability.

### Originality

Cascade focuses on the breach-coach coordination layer instead of detection or post-incident compliance reporting. The room-based privilege architecture, dynamic jurisdictional agent discovery, and adversary-agent separation of duties create a differentiated workflow for regulated, high-stakes incident response.
